# Selector de costo de adquisición

- El selector cerrado muestra únicamente el valor de costo seleccionado en USD.
- Al abrir el desplegable se mantiene el detalle completo del promedio y de cada equipo.
- El detalle del equipo seleccionado también queda disponible como tooltip.
- Se eliminó la línea redundante "Costo usado" debajo del selector.
